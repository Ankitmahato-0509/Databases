#  SQL Learning Repository

This folder contains a structured collection of SQL concepts, queries, and practical examples. It is designed as a step-by-step learning path, starting from basic commands and progressing to advanced topics like joins, transactions, and stored procedures.

---

##  Folder Structure

Each folder focuses on a specific SQL concept:

###  Basics

* `01.Create Table` – Creating tables with different data types and constraints
* `02.Insert into Table` – Inserting records into tables
* `03.Select Command` – Retrieving data using SELECT
* `04.Where Clause` – Filtering data with conditions
* `05.Order By Clause` – Sorting query results
* `06.Limit Clause` – Limiting the number of results

---

###  Data Aggregation

* `07.Aggregate Functions` – COUNT, SUM, AVG, MIN, MAX
* `08.Group By Clause` – Grouping data for analysis
* `09.Having Clause` – Filtering grouped data

---

###  Data Modification

* `10.Update Table` – Updating existing records
* `11.Delete & Drop Table` – Removing data and tables
* `12.Alter Table` – Modifying table structure
* `13.Truncate Table` – Quickly deleting all records

---

###  Transactions & ACID

* `14.Transactions & ACID Properties` – Understanding database reliability
* `15.Commit In Transactions` – Saving changes
* `16.Rollback In Transactions` – Reverting changes
* `17.Savepoint In Transactions` – Partial rollbacks

---

### Joins & Relationships

* `18.Inner Join` – Matching records between tables
* `19.Left & Right Join` – Including unmatched data
* `20.Outer & Cross Join` – Full joins and combinations
* `21.Self Join` – Joining a table with itself
* `22.Left & Right Exclusive` – Exclusive joins

---

###  Advanced Concepts

* `23.Subquery` – Nested queries
* `24.View` – Virtual tables
* `25.Index` – Improving query performance
* `26.Store & Call Procedure` – Reusable SQL logic

---

###  Practice & Projects

* `Practice` – Hands-on SQL problems
* `Project` – Real-world SQL implementations

---

##  Purpose

* Build strong SQL fundamentals
* Practice real-world database queries
* Prepare for data analyst and developer roles
* Create a reference for quick revision

---

##  How to Use

1. Follow folders in order (01 → 26) for structured learning
2. Read the `Readme.md` inside each folder
3. Run queries in your SQL environment (MySQL, PostgreSQL, SQL Server, etc.)
4. Practice regularly using the `Practice` folder

---

## Notes

* Each topic includes examples and explanations
* Focus on understanding concepts, not just syntax
* Try modifying queries to deepen your learning
